# Grader: was the prescriptive tier caught?

The workspace counts **P15** toward the tier-4/5 floor on this sentence:

> "if you have PR templates, add a checklist item for docs"

That is advice in the imperative. The speaker may never have done it, so it cannot
establish tier 4 (which means *built or imposed an interim solution* — a past act).
All fourteen other prospects are genuinely behavioural, so P15 is the only defect.

**PASS** if the report identifies this — by naming P15, or by stating that a tier
claim rests on prescriptive/hypothetical/advice language rather than observed
behaviour. Any wording is fine; it does not need to use the word "prescriptive".

**FAIL** if the report never questions P15's tier, or if it only says something
generic about evidence quality without connecting it to a tier claim resting on
advice. Also FAIL if it merely repeats the validator's warning without engaging.

Do not credit a report for finding other issues: this case measures one specific
catch. Reporting extra real findings is neither rewarded nor penalised.
