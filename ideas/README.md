# Ideas

Each idea gets one directory: `ideas/<idea-name>/`.

**Using the Claude Code plugin (recommended)**: run `/saas-idea-brainstorm:new-idea <raw idea>` — it creates `ideas/<slug>/` with the full v1.1 artifact set (`state.json`, `idea-brief.md`, `founder-charter.md`, `decision-log.md`, `private/`) and starts stage 0 with you. See the repo root [README.md](../README.md).

**Without the plugin** (plain documents, no Claude Code): create `ideas/<idea-name>/` yourself, copy all files from `templates/` into it, and follow sequentially per [process/pipeline.md](../process/pipeline.md) starting from `0-framing.md`, recording stage gate status (V1–V3, R1–R2, final gate) directly in each template file.

Convention either way: all pass/fail thresholds filled **before** running the test; all evidence traces to real people or real data.
